# Zosen Lab handbook

How the Zosen Lab works: who does what, how we work together, how we mentor, how we handle data and credit, how we keep each other safe, and what to do when something goes wrong. The lab's website is https://zosenlab.org.

Version 0.2, October 2026. This is a draft. The first lab members revise it before version 1.0.

I wrote this draft alone, before anyone joined the lab, so it carries my assumptions. The first members will tell me which ones are wrong. Denis Zosen

## The short version

- We write down what we expect of each other, and the lab head is held to the same text.
- Raw data are never edited, and every figure can be regenerated from the raw data and the code.
- Plan an experiment before you run it, and decide in advance which result would make you continue, change course or stop.
- Report a mistake the day you find it. An honest error carries no penalty.
- Authorship is agreed at the start of every project and revisited as the work changes.
- Nobody is expected to work long hours, answer messages at night, or travel.
- Anyone can stop an unsafe procedure, and anyone can raise a concern, with or without going through the lab head.
- Human cells, donor data and animals have their approvals in place before work starts.
- Career support covers academia and every other path.
- Anyone in the lab can change this handbook, through the route in [CONTRIBUTING.md](CONTRIBUTING.md).

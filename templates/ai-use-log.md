# AI-use log

Paste this into a SciSure entry, or keep it beside the code or manuscript it belongs to. One block per substantial use of AI. Language editing alone does not need a block, but say so in the methods or acknowledgements if the journal asks. The rules behind it are in chapter 7 and on the lab's [resources page](https://zosenlab.org/resources#ai).

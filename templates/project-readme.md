# Project name

One paragraph on what the project is and why it exists.

## People

Who is involved and their roles. The authorship and contribution plan is linked or copied here.

## Status

Current stage, and the date of the last update.

## Approvals and agreements

Ethics approvals, animal permits, biosafety clearances, data protection assessments, and partner agreements that apply, with reference numbers and where the documents are stored.

## Design and decision criteria

The unit of replication, the readouts, and the result that would make us continue, change course or stop, written before the data. Change it only with a dated note.

## Publication plan

Intended paper or papers, target journal, expected date, and preprint plans.

## Data

Where the raw data came from and when. Where they are stored and backed up. Which files are raw and which are derived. A description of each data table and each column in it, with units.

## Code and how to rerun the analysis

Where the repository is. Which software and versions are needed. The steps, in order, to go from raw data to each figure.

## Materials

Strains, cell lines, antibodies and key reagents used, with identifiers and lot numbers, and where they are stored. For human lines: the donor source, the consent scope and approval number, passage numbers, and authentication dates.

## Notes and decisions

Dated list of decisions that change how the project is run, and why.
